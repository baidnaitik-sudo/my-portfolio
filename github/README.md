# GitHub Assets & Repository Guide

This folder is set up for your GitHub repository assets, screenshots, and guides.

### Useful Git Commands:
```bash
# Initialize git if not already done:
git init

# Add all files:
git add .

# Commit changes:
git commit -m "feat: scrapbook and technical portfolio styling"

# Link to your remote GitHub repository:
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# Push to main:
git branch -M main
git push -u origin main
```
